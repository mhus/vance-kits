The user has a structurally-sound draft and wants
line-level polish. Sentences clearer, words sharper,
sentences tighter. This is the third pass; if structure
is wrong (`structural-edit`) or tone is off
(`tone-and-voice`), copy-editing wastes effort.

Copy-editing is about *removing friction*. Each sentence
the reader stumbles on is friction. Less friction = the
reader gets your meaning faster, with less effort, with
less misread.

## Default protocol

1. **Confirm structure is settled.** If the user is still
   debating "should this section be earlier?", they're not
   ready for copy-edit. Send them to `structural-edit`.
2. **Read the piece aloud (or imagine it).** Stumbles
   reveal sentences to fix. Cadence problems show up in
   reading but not in silent rereading.
3. **Pass 1 — clarity.** Each sentence should mean one
   thing, clearly. Where you have to re-read, fix.
4. **Pass 2 — tightening.** Drop weak words, hedges,
   filler. See `weak-words-and-fillers`.
5. **Pass 3 — grammar / mechanics.** Last; otherwise you
   polish lines you'll cut. See `grammar-without-pedantry`.
6. **Read again.** Final read for cadence. The piece
   should pull the reader through.

## On-demand manuals

- `line-level-pass` — what to look at sentence-by-sentence:
  passive vs. active, sentence length variety, opening
  words, end-of-sentence emphasis, awkward inversions,
  buried subjects.
- `grammar-without-pedantry` — grammar choices that
  matter for clarity vs. ones that are zombie rules
  (split infinitive, sentence-ending preposition,
  starting with "and"). When to follow style; when to
  break.
- `weak-words-and-fillers` — adverbs, hedges, "very",
  "really", "actually", "in fact", redundant pairs,
  zombie phrases. Specific cuts that almost always
  improve.

If you're not sure where the friction is, read aloud and
follow the stumbles.

## Hard rules

- **Don't change structure here.** If a sentence is
  fundamentally wrong because the surrounding paragraph
  is wrong, that's structural. Mark it; come back later.
- **Don't strip voice in the name of "professionalism".**
  The user's distinctive voice is not the bug. Some
  awkwardness is on purpose.
- **Don't impose rules over readability.** "Don't end with
  a preposition" — break the rule if the rule-followed
  sentence is clunkier. Clarity beats orthodoxy.
- **Don't standardise everything.** A piece with all
  sentences the same length, same shape, same opening
  word, reads dead. Copy-editing should *preserve* and
  refine variety, not flatten it.
- **Don't fix what works.** A surprising long sentence
  that lands; a deliberately fragmented one. If it works,
  leave it. Copy-edit is about removing friction; it's
  not about making everything one shape.
- **Pass discipline.** Don't mix passes (clarity in pass
  1, polish in pass 3). Each pass is a focused mode;
  mixing exhausts attention faster and produces worse
  edits.

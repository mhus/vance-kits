# When to Stop — closing a thinking pass without forcing a verdict

Skill-agnostic guidance. The temptation in any structured-thinking
mode is to push for a verdict because the user "asked for help".
Often the right output is to stop and tell the user what's missing.

## Signals that the pass is done

- The user has a **clear next step** (even if not a verdict).
- The **uncertainty is named** — what's known, what's guess, what's
  unknown.
- The **constraints are explicit** — what would have to be true
  for option A vs. B to be right.
- The user can **defend the answer to themselves** without you in
  the room.

When all four are present, stop. A verdict on top of those four is
optional and often noise.

## Signals that the pass is *not* done — keep going

- The user is **scoring with vibes**. Push them to ground criteria
  in evidence or own the guess explicitly.
- A **major option is unexplored**. "We've been comparing A and B
  but haven't talked about doing nothing."
- The **gut and the matrix disagree** and you haven't named why
  (see decision-frame full-protocol §5).
- The user is **anchored on a single criterion** (cost, speed)
  and ignoring the others.

## Signals that the pass should *halt*, not close

Sometimes the right move is to stop without resolution and tell the
user to come back later:

- **Insufficient information.** "You don't have enough to decide.
  Go look up X, talk to Y, then come back."
- **Wrong question.** "I think the real question is upstream of
  this — you're choosing between symptoms."
- **Too tired / too soon.** Decisions made under fatigue or
  freshly-emotional state regress to the mean. "Sleep on it;
  revisit Tuesday."
- **Forcing-function works.** "Decide by Friday or default to A."
  Useful for users who'd otherwise loop indefinitely.

## Anti-patterns

- **Manufactured certainty.** Picking a side because the user
  asked for one, despite the inputs being weak. Don't.
- **False precision.** A 0.73 vs. 0.81 score on vibes-input.
  Better: "A feels stronger but I'm uncertain — here's why".
- **Restating without progressing.** Three paragraphs that say the
  same thing. Cut.
- **Solution-imprinting.** Mentioning a specific tool / vendor /
  framework before the user has named the criteria. The user
  follows the imprint, you've shaped the decision.

## Output line

End the pass with one of:

- "**Recommendation:** ⟨next step⟩."
- "**Halted because:** ⟨what's missing⟩."
- "**You decide.** Here's the trade map."

Pick the one that's true, not the one that sounds most decisive.

# When is a Draft Publishable?

The editorial approval decision (step 2 of the review-publish
process) is not a matter of taste — it is a checklist. A draft is
**publishable** only when all of these hold:

- **Complete.** No `TODO`, no `[placeholder]`, no "…to be written"
  sections. Every promised section is actually written.
- **Accurate.** Factual claims are grounded — no invented numbers,
  names, or dates.
- **On length.** Within the brief's target range; not a stub, not
  bloated.
- **On tone.** Matches the publication's voice (the brief states
  which).

If any item fails, the editor **requests changes** and names the
failing item(s) in the notes so the writer knows what to fix.

## Notes carry forward

When the editor requests changes, the specific failing items become
the writer's revision task for the next round. The revise step
should address exactly those notes — not rewrite the whole piece.
